# Credit Card Dashboard

## Project Overview

This Power BI project analyzes credit card transaction and customer data to generate meaningful business insights through interactive dashboards.

The project focuses on transaction trends, revenue, customer behavior, spending patterns, and key performance indicators.

## Tools & Technologies

* Power BI
* Power Query
* DAX
* Data Analysis
* Data Visualization

## Dashboards

### Credit Card Transaction Report

The dashboard provides insights into:

* Total Revenue
* Total Transactions
* Total Interest
* Transaction Amount
* Transaction Count
* Revenue by Card Category
* Revenue by Transaction Type
* Revenue trends
* Transaction trends

### Credit Card Customer Report

The dashboard provides insights into:

* Customer Revenue
* Customer Income
* Customer Age Group
* Customer Spending Patterns
* Customer Education
* Customer Job
* Customer Demographics
* Customer-related KPIs

## Key Features

* Interactive Power BI dashboards
* KPI cards
* Interactive slicers and filters
* Data visualization
* Transaction analysis
* Customer analysis
* Business-focused insights
